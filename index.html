Material 3 для Steam на Android

steamd — патч, который перекрашивает официальное приложение Steam в спокойную палитру Material 3, меняет шрифт и подключает свою тему для магазина и новостей.

Что меняет патч

palette

Палитра M3

Встроенная тема приложения получает тёмные поверхности и мягкий голубой акцент. Меняются меню, Steam Guard, навигация и шапки.

 text_fields

Свой шрифт

Motiva Sans заменяется любым шрифтом с нужными начертаниями, например Roboto. Насыщенность и курсив подбираются автоматически.

 storefront

Тема магазина

Магазин и новости открываются в WebView. В них подгружается CSS с этого сайта, поэтому тему можно обновлять без пересборки приложения.

Палитра

Слева исходный цвет темы приложения, справа цвет после патча.

warning

Перед установкой запишите код восстановления Steam Guard

Пропатченное приложение подписано другим ключом, поэтому официальное нужно удалить. Вместе с ним удаляются данные Steam Guard. Код восстановления (R-xxxxx) находится в Steam → Steam Guard.

Установка

Понадобятся: Python 3.10+, Java 11+, adb, uber-apk-signer и статические TTF-шрифты (например, Roboto).

1
Установить зависимости
pip install hermes-dec fonttools
 2
Скачать все APK приложения (base и split)
adb shell pm path com.valvesoftware.android.steam.community
adb pull <path> apk/
 3
Пропатчить base.apk
python patch/patch_steam.py apk/base.apk out/base.apk --fonts fonts/
 4
Подписать все APK одним ключом
cp apk/split_*.apk out/
java -jar uber-apk-signer.jar --apks out --allowResign -o signed
 5
Заменить официальное приложение
adb uninstall com.valvesoftware.android.steam.community
adb install-multiple signed/*.apk

После установки войдите в аккаунт и заново привяжите Steam Guard. Откатиться можно в любой момент: удалите пропатченное приложение и установите Steam из Google Play.
